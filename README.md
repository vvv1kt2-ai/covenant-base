# Парсер ковенантов облигаций

Автоматический парсинг раздела **5.6.1 «Досрочное погашение облигаций по требованию владельцев»** из эмиссионных документов российских облигаций + парсинг программ облигаций с [e-disclosure.ru](https://e-disclosure.ru/).

## Архитектура

```
ISIN-список
  ├─→ bonds.finam.ru (Playwright) → PDF-документ → pdfplumber → JSON → Excel
  └─→ e-disclosure.ru (Playwright) → ZIP/PDF программ → pdfplumber → JSON
```

| Этап | Технология | Описание |
|------|-----------|----------|
| Поиск карточки | Playwright | Обход ServicePipe anti-bot на bonds.finam.ru |
| Скачивание PDF | httpx | Статический хостинг st.finam.ru (без антибота) |
| Парсинг программ | Playwright | Поиск companyId по ISIN на e-disclosure.ru, скачивание ZIP/PDF |
| Извлечение текста | pdfplumber | Парсинг раздела 5.6.1 + секций программ (9.5, 9.3, 6.5.1 и др.) |
| Классификация | — | 7 категорий ковенантов |
| Экспорт | openpyxl | JSON → Excel с подсветкой ошибок и ковенантов из программ |

## Быстрый старт

### Зависимости

```bash
pip install playwright httpx beautifulsoup4 lxml pdfplumber openpyxl
playwright install chromium
```

### Основной парсинг

```bash
# Все ISIN из CSV
python parser.py --input BBB.csv

# Один ISIN
python parser.py --isin RU000A105TG7

# С лимитом
python parser.py --input BBB.csv --limit 10

# Дозагрузка (пропустить обработанные)
python parser.py --input BBB.csv --resume

# Повторить ошибочные
python parser.py --input BBB.csv --retry-errors
```

### Парсинг программ (Finam)

```bash
# Пилот: 4 ISIN
python pilot_programs.py

# Масштаб: все 46 ISIN с programs
python parse_programs.py

# Мерж в results.json
python merge_programs.py
```

### Парсинг программ (e-disclosure.ru)

```bash
# Пилот: 6 эмитентов ( companyId кэшируются в company_ids.json )
python edisclosure_pilot.py

# Мерж
python merge_edisclosure.py
```

### Экспорт в Excel

```bash
python export_excel.py                        # results.json → covarianants.xlsx
python export_excel.py output.xlsx            # указать имя выходного файла
```

## Категории ковенантов

| Категория | Описание |
|-----------|----------|
| Раскрытие отчётности | Промежуточная, годовая, консолидированная отчётность эмитента, поручителя, связанной стороны |
| Выплата дивидендов, распределение прибыли | Ковенанты на выплату дивидендов |
| Утрата контроля | Отчуждение, снижение доли, активов |
| Долговая нагрузка | Задолжённость, кредиторская, целевое использование |
| Кросс-дефолт | Дефолт по иным обязательствам |
| Делистинг | Снятие с торгов на биржах |
| Иное | Не попало в остальные категории |

## Логика парсинга раздела 5.6.1

### 1. Проверка наличия

Первые 5 текстовых строк раздела проверяются на ключевые фразы:
- не предусмотрена/о/ы
- не установлена/о/ы
- не предоставлена/о/ы

Если найдено → **0 ковенантов**.

### 2. Извлечение событий (5 паттернов + disclosure filter)

| # | Паттерн | Описание |
|---|---------|----------|
| 1 | `Событие досрочного погашения ... – N:` | Формулировка вида «Событие досрочного погашения ... – 1:» |
| 2 | `Событие N:` в начале строки | Именительный падеж + двоеточие |
| 3 | Список `N)` или `N).` | Нумерованный список, ≥50% ключевых слов |
| 4 | Буллеты `✓/-/–/—/•/◆/▪/•` | ≥2 элемента в списке |
| 5 | Single bullet | Один буллет с ключевыми словами |
| — | Plain text triggers | Прямые упоминания делистинга, ликвидации и т.д. |

### 3. Фильтры

- **Disclosure filter**: пропускает procedural-записи («В Ленте новостей», «Порядок раскрытия»)
- **Фильтр дат**: пропускает «является/считается/наступает/возникает»
- **Дедупликация**: по номеру события

## Защита от блокировок

- bonds.finam.ru: задержка **20–45 сек** между запросами, обход ServicePipe
- e-disclosure.ru: задержка **15–30 сек**, CAPTCHA с ручным вводом (120 сек таймаут)
- Автопауза **5 мин** после 3 последовательных ошибок
- Перезапуск браузера при сбоях
