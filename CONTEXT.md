# Контекст проекта: Парсинг эмиссионной документации облигаций с Finam

## Доменная модель

### Источники данных
- **bonds.finam.ru** — основной источник. Карточки выпусков облигаций с ссылками на PDF-документы (решения о выпуске, программы облигаций). Использует ServicePipe anti-bot protection (JS challenge). URL карточек: `https://bonds.finam.ru/issue/details{ID}/default.asp`
- **e-disclosure.ru** — запасной источник. Документы по рег. номеру эмитента (не по ISIN). Требует CAPTCHA + Playwright. URL: `https://e-disclosure.ru/portal/files.aspx?id={source_id}&type=7`

### Ключевые сущности
- **ISIN** — международный код ценной бумаги (например, RU000A1089A3). Основной ключ поиска.
- **Решение о выпуске** — PDF-документ, содержащий условия эмиссии. Содержит пункт 5.6.1 "Досрочное погашение облигаций по требованию их владельцев".
- **Программа облигаций** — PDF-документ, на который ссылается решение. Содержит полные условия погашения.
- **Ковенант** — условие/ограничение в эмиссионной документации. Категории: информационный, финансовый и т.д.

## Технические решения
- **Язык**: Python
- **Зависимости**: pdfplumber (парсинг PDF), httpx (HTTP), beautifulsoup4 (HTML), playwright (обход anti-bot), openpyxl (Excel)
- **venv**: существующий `D:\data-scraping\venv` (playwright, httpx, bs4, lxml уже установлены; нужно добавить pdfplumber, openpyxl)
- **Кэширование**: PDF-файлы кэшируются в `downloads/`
- **Rate limiting**: 1-2 сек паузы между запросами + рандомизация
- **Логирование**: в файл + консоль
