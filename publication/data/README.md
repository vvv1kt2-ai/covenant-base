# publication/data — что здесь должно лежать

Каталог входных и выходных данных публикационного слоя. **Содержимое в git не отслеживается**
(см. `.gitignore`): реестры и готовый материал содержат данные по эмитентам и остаются
в рабочей копии. В репозитории — только этот перечень, чтобы структура была воспроизводима.

## Входные

| Файл | Что это | Откуда |
| --- | --- | --- |
| `Реестр_ковенантов B.xlsx` | реестр группы B (16 колонок) | рабочий каталог проекта |
| `Реестр_ковенантов BB_ИТОГ.xlsx` | реестр группы BB (19 колонок) | рабочий каталог проекта |
| `Реестр_ковенантов BBB.xlsx` | реестр группы BBB (17 колонок) | рабочий каталог проекта |
| `new_issues_covenants.xlsx` | новые выпуски, раскладываются по группам | `add_new_issues.py` парсера |
| `ПВО_справочник.xlsx` | справочник ПВО: листы «ПВО», «По выпускам», «Список ЦБ» | `fetch_pvo.py` + `resolve_pvo.py` |

## Выходные

| Файл | Что это | Кем создаётся |
| --- | --- | --- |
| `Ковенанты_для_публикации.xlsx` | основной материал: листы `B`, `BB`, `BBB`, `Легенда`, `ПВО`, `Исключения` | `build_covenant_publication.py` |
| `Ковенанты_для_публикации.md` | та же таблица для вставки в публикацию | `build_covenant_publication.py` |
| `Ковенанты_для_публикации_обновлено.*` | предыдущий снимок (до добавления колонки ПВО) | история |
| `Непубликовавшие_ПВО.xlsx` | таблица «компания — ПВО» для не публиковавших отчётность | `build_missing_pvo.py` |
| `Проверка_непубликовавших_ковенанты.xlsx` | есть ли информационный ковенант у не публиковавших | `check_missing_covenants.py` |
| `tmp/` | кэш и резервные копии, промежуточные JSON | все скрипты |

## Каталог вне репозитория

`publication/img/` — растровые версии материала (`build_covenant_images.py`), тоже
не отслеживается.

## Восстановление структуры

Скопировать перечисленные входные файлы из рабочего каталога проекта, затем из корня
репозитория:

```bash
python publication/tools/build_covenant_publication.py
```

Пути по умолчанию указывают сюда; внешние источники — через `COVENANT_MOEX`
и `COVENANT_SCRAPE`, см. `../README.md`.
